# Wiki do Educacross Frontend

Bem-vindo à Wiki oficial do **Educacross Frontend**! Esta é uma plataforma educacional inovadora que oferece jogos e atividades digitais para apoiar o processo de ensino-aprendizagem. Aqui você encontrará informações detalhadas sobre a arquitetura, desenvolvimento e manutenção do projeto.

## 🎯 Sobre o Projeto

O **Educacross** é uma plataforma educacional que permite:

- Criação e gerenciamento de missões educativas personalizadas
- Acompanhamento do desempenho de estudantes
- Integração com sistemas educacionais
- Suporte a múltiplas marcas (white-label)
- Gamificação do processo de aprendizagem

## 🛠️ Tecnologias Principais

- **Vue.js 2** - Framework JavaScript reativo
- **Vuex** - Gerenciamento de estado
- **Vue Router** - Roteamento SPA
- **Bootstrap Vue** - Componentes UI
- **Tailwind CSS** - Framework CSS utilitário
- **Jest** - Framework de testes
- **Axios** - Cliente HTTP
- **Docker** - Containerização

## 🌟 Funcionalidades Principais

- **Missões Educacross**: Conjuntos de jogos sugeridos pela equipe pedagógica
- **Missões Personalizadas**: Criação de missões customizadas pelos professores
- **Relatórios de Desempenho**: Análise detalhada do progresso dos estudantes
- **Sistema Multi-tenant**: Suporte a diferentes marcas e instituições
- **Integração Microsoft**: Autenticação e serviços Microsoft
- **White-label**: Customização visual por marca
